# Nucleus issue tracker

This repository is the bug and feature tracker for **Nucleus**, a .NET networking engine with a Unity integration. It holds no code. The engine source is not public, so there is nothing here to clone, build or read.

**[Open an issue](https://github.com/FirstGearGames/nucleus-issues/issues/new/choose)**

## What belongs here

- **Bug reports.** Something in Nucleus behaves incorrectly and you can describe how to make it happen.
- **Feature requests.** Nucleus cannot do something you need it to do.

Both go through a form that asks for the facts an investigation needs: your version, edition, transport and topology. Those four decide which code path ran, and without them a report usually cannot be acted on.

## What does not belong here

- **Support questions.** How to do something, why your project will not compile, whether an approach is sound. Start with the [documentation](https://nucleus-networking-docs.pages.dev/docs/v1/).
- **Pull requests.** This repository does not accept them, and any that are opened are closed automatically. There is no source here to change.

## Before you file a bug

Please read **[Reporting a bug](https://nucleus-networking-docs.pages.dev/docs/v1/reference/reporting-a-bug/)**. It covers the part the form cannot: building a project that reproduces the fault, in under 1 MB, that someone else can open and run.

Most reports that go unfixed are not ignored. They simply could never be reproduced. An issue without a reproduction project is investigated at lower priority, and may be closed if it cannot be reproduced.
